# Persistence Layer Structure

The ORM in app/orm/ defines core entities using SQLAlchemy: database.py handles engine/session creation with SQLite (file-based via conf_data()["db"], WAL mode, thread-safe connect_args); Base metadata for declarative models. job.py models Job with fields (id: str PK, owner/set/name/kind/state: str indexed, drop_done: bool, param/detail: str, pid: int indexed, start/end: DateTime indexed). schedule.py models Schedule with fields (id: int PK autoincrement, schedule/set/name/owner: str indexed, active/drop_done: bool indexed, param: str, last: DateTime indexed). No relationships or revisions table; code history via git (committed/unstaged). Sessions via get_db_engine() (thread-local DbEngine), scoped per request in web.py (dependency). Base.query (or session.get/scalar) for CRUD in routers/lib/runner.py. SQLite implied via paths in runner.py/conf; no advanced features (e.g., no joins beyond basic filters).
