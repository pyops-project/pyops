# Task Logging Capture

In app/runner.py run(), creates workspace directory with stdout.log and stderr.log files. Redirects stdout to stdout.log and stderr to stderr.log using contextlib.redirect_stdout and redirect_stderr. Configures root logger: root.setLevel(logging.INFO); adds StreamHandler(sys.stdout) with level INFO and filter for records < logging.WARNING (INFO records to stdout.log); adds StreamHandler(sys.stderr) with level WARNING (WARNING+ records to stderr.log). Processes param, libs, and code for ! install lines (pip/git via venv). Executes param, libs, code within redirects and glob (userspace/setspace/workspace, control, listener for service/debug). On success: queues "done" with detail=None. On failure: queues "failed" with detail=traceback.format_exc(). Log files in workspace capture execution output. Applies to all kinds (task/service/debug). Preserves install processing, glob vars; no changes to pyops.json or app logger. Handles empty files.
