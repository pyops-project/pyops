# VSIX Extension Substructure

vsix/src/extension.ts defines activation/deactivation: Registers RemoteContentProvider for text documents (provideTextDocumentContent fetches HTML via HTTP), PyOpsWebviewViewProvider for webview (resolveWebviewView loads HTML with title, _getHtmlForWebview injects scripts/styles), ManagerTreeDataProvider for tree views (fetchScriptlets downloads from API, getChildren builds hierarchy, refresh updates). jobsTreeProvider.ts defines JobsTreeDataProvider: fetchJobs from API, getChildren filters by state (todo/running/done), getTreeItem with icons/actions. Subdirs: commands/ for bulk actions (cancel/delete), config/ for settings, providers/ for tree/webview, status/ for connection, utils/ for helpers (inferExt/getIconForType), views/ for UI. Extension uses vscode API for events (onDidChange), HTTP fetches with headers, no direct DB access.
